# Explainability Guide — How to Read the Graphs and Outputs

This document explains **what the explainability analysis actually does**, **what each plot type shows**, and **how to present the findings** in a report, viva, or dashboard demo.

Explainability runs at two levels:
- **Stage 1:** Why does the model predict a barrier? (SHAP on barrier targets)
- **Stage 2:** Why does the model predict a health outcome? (SHAP + odds ratios on ANC gap / unmet FP)

---

## 1. What "explainability" means in this project

Machine learning models output probabilities, but stakeholders also need to know **which factors drive those predictions**.

| Method | Model(s) | What it tells you | Limitation |
|--------|----------|-------------------|------------|
| **Odds ratios (LR coefficients)** | Stage 1 & 2 Logistic Regression | Direction and strength of association per feature | Assumes linear log-odds; one feature at a time |
| **Feature importance (RF/XGB built-in)** | Stage 1 & 2 tree models | Which features the trees split on most often | No direction (risk vs protective) |
| **SHAP (SHapley Additive exPlanations)** | Stage 1 & 2 RF/XGB | Per-feature contribution to each prediction; direction + magnitude | Computed on a subsample for speed |
| **Barrier-uplift chart** | All Stage 2 models | Does adding barrier probabilities improve AUC beyond demographics? | Summary metric only — not per-feature |
| **AOR vs SHAP comparison** | Dashboard | Ranks base-paper AOR against ML SHAP rankings | Association ≠ causation |

**Critical framing for all outputs:** These are **predictive / associational** explanations, not causal claims. Say "associated with higher predicted risk," not "causes."

## 2. Stage 1 explainability

### 2.1 Logistic regression odds ratios

**File:** Printed during training; compare with base paper Table 2 (AOR).

| Column | Meaning |
|--------|---------|
| `Coefficient` | Log-odds change per one-unit increase in feature |
| `OddsRatio` | exp(coefficient) — multiplicative effect on odds |

**How to interpret:**
- OddsRatio **> 1** → feature associated with **higher** barrier odds (risk factor)
- OddsRatio **< 1** → feature associated with **lower** barrier odds (protective factor)
- OddsRatio **= 1.05** → 5% higher odds per unit increase

**Example narrative:** "Women in the poorest wealth quintile have 2.1× the odds of reporting a household barrier compared to the richest quintile, holding other features constant."

### 2.2 Stage 1 SHAP plots (RF / XGBoost)

**Location:** `outputs/stage1_results/shap_plots/` and `data/dashboard/powerbi/images/rf_bar_*.png`, `rf_summary_*.png`

Generated by: `src/shap_analysis/shap_plots.py`, notebooks 04 and 05

#### Plot type A: SHAP bar chart (`rf_bar_{target}.png`)

```
Features listed vertically | Bar length = mean |SHAP value|
```

| What it shows | Global feature ranking — which inputs matter most on average |
| How to read | Longer bar = stronger average impact on model output |
| Color | Usually single color; ranking matters more than color |
| X-axis | Mean absolute SHAP value (magnitude of impact) |

**Say in a presentation:** "The top three drivers of household barrier prediction are wealth index, media exposure, and education level."

#### Plot type B: SHAP beeswarm / summary (`rf_summary_{target}.png`)

```
Each dot = one woman | X-axis = SHAP value | Color = feature value (red=high, blue=low)
```

| What it shows | Both **magnitude** and **direction** of each feature's effect |
| How to read | Dot far right → pushes prediction toward barrier=1; far left → toward barrier=0 |
| Color pattern | Red dots on the right → high feature values increase barrier risk |
| Y-axis | Features ranked by importance (top = most impactful) |

**Example reading:** "High wealth index (blue dots) clusters on the left (negative SHAP) — richer women get lower predicted barrier probability."

## 3. Stage 2 explainability

Stage 2 explainability focuses on **health outcomes**, with barrier probabilities and cluster membership as key inputs.

**Primary module:** `src/shap_analysis/stage2_shap.py` (publication-quality RF plots)  
**Also:** `run_shap_analysis()` in `stage2_random_forest.py` and `stage2_xgboost.py`

### 3.1 Stage 2 logistic regression — odds ratios

**Files:** `outputs/stage2_results/logistic_coefficients_target_unmet_fp.csv`, `logistic_coefficients_target_anc_gap.csv`

Top predictors for **unmet family planning need** (actual run):

| Feature | OddsRatio | Interpretation |
|---------|-----------|----------------|
| v501_married | 1.38 | Married women higher odds of unmet need (in eligible subsample) |
| household_barrier_prob | 1.15 | Higher predicted household barrier → 15% higher odds of unmet need |
| v106 (education) | 1.14 | Higher education level coded value → higher odds in this model |
| vulnerability_score | 1.06 | More vulnerable → slightly higher odds |

**Note:** Some coefficients may seem counterintuitive in isolation because features are correlated and the model is multivariate. Always report them as "adjusted associations in the fitted model," not standalone causal effects.

### 3.2 Stage 2 SHAP plot catalogue

All plots below are generated for **Random Forest** (and similar variants for XGBoost) on the **test-set subsample**.

#### Plot 1: SHAP Summary / Beeswarm (`shap_summary_target_unmet_fp.png`)

**What it explains:** Global picture — which features push predictions toward unmet FP need across the test population.

| Element | Meaning |
|---------|---------|
| Each row | One feature (human-readable label via `feature_labels.py`) |
| Dot position (x) | SHAP value for one woman — positive = higher predicted unmet need |
| Dot color | That woman's actual feature value (red = high, blue = low) |
| Spread | Wider cloud = more heterogeneous effect |

**How to present:** "Barrier probability features appear in the top 10, confirming that Stage 1 barrier exposure is associated with Stage 2 outcome risk even after controlling for demographics."

#### Plot 2: SHAP Bar (`shap_bar_target_unmet_fp.png` / `rf_shap_bar_*.png`)

**What it explains:** Ranked list of average feature impact (mean |SHAP|).

| Element | Meaning |
|---------|---------|
| Bar length | Average absolute contribution to model output |
| Numbers on bars | Exact mean |SHAP| values |
| Top features | The levers the model relies on most |

**Difference from beeswarm:** Bar chart shows **magnitude only** — no direction. Use beeswarm when you need to explain "high values increase vs decrease risk."

#### Plot 3: SHAP Waterfall (`shap_waterfall_target_unmet_fp.png`)

**What it explains:** **One individual's** prediction decomposed step by step.

| Element | Meaning |
|---------|---------|
| Starting bar (base value) | Model's average predicted log-odds / probability |
| Red bars | Features pushing this woman toward **higher** unmet-need risk |
| Blue bars | Features pushing toward **lower** risk |
| Final bar | Her total predicted risk |

**Which individual?** The woman with the **highest total positive SHAP sum** in the sample (highest predicted risk case).

**How to present:** "For this high-risk woman, elevated household barrier probability and low digital inclusion contribute most to her predicted unmet need."

#### Plot 4: SHAP Dependence (`shap_dependence_target_unmet_fp.png`)

**What it explains:** How **one feature's value** relates to its SHAP contribution, optionally coloured by a second (interaction) feature.

| Element | Meaning |
|---------|---------|
| X-axis | Raw feature value (e.g. household_barrier_prob from 0 to 1) |
| Y-axis | SHAP value for that feature |
| Trend | Upward slope → higher feature values increase predicted risk |
| Dot color | Values of another feature (interaction hint) |

**How to present:** "As predicted household barrier probability increases from 0.3 to 0.7, its marginal contribution to unmet-need prediction rises steadily."

#### Plot 5: SHAP Heatmap (`shap_heatmap_target_unmet_fp.png`)

**What it explains:** SHAP values for **many individuals at once** (up to 500 rows), sorted to reveal cohort patterns.

| Element | Meaning |
|---------|---------|
| Each row | One woman in the SHAP subsample |
| Each column | One feature |
| Cell color | SHAP value (red = pushes toward positive class) |
| Row sorting | Groups similar explanation profiles together |

**How to present:** "Blocks of red in the barrier-probability columns indicate subgroups where barrier exposure consistently drives high predicted risk."

#### Plot 6: SHAP Group Comparison (`rf_shap_group_comparison_target_unmet_fp.png`)

**What it explains:** Total SHAP mass split across **three feature groups**:

| Group | Features included |
|-------|-------------------|
| Stage 1 barrier probs | household, logistic, facility OOF probabilities |
| Cluster features | cluster_0, cluster_1 dummies |
| Socioeconomic / other | All remaining Stage 1 features |

| Element | Meaning |
|---------|---------|
| Bar height | Sum of mean |SHAP| for all features in that group |
| Comparison | Which block of inputs the model "spends" most explanation budget on |

**How to present:** "Socioeconomic features contribute the largest share of SHAP mass, but barrier probabilities add a distinct increment — supporting the Stage 2 research design."

#### Plot 7: Cluster SHAP Comparison (`shap_cluster_compare_target_unmet_fp.png`) — when generated

**What it explains:** Whether the **same feature** has different explanatory power in different K-Means clusters.

| Element | Meaning |
|---------|---------|
| Rows | Top features by overall SHAP |
| Columns | Cluster 0 vs Cluster 1 |
| Cell value | Mean |SHAP| for that feature within that cluster |

**How to present:** "Household barrier probability has higher |SHAP| in Cluster 0 (high vulnerability), meaning barrier exposure is a stronger predictor within that archetype."

### 3.3 Barrier-uplift chart (`barrier_uplift_comparison.png`)

**What it explains:** Does adding barrier + cluster features improve **ROC-AUC** over socioeconomic features alone?

```
Two bars per model:
  [Socioeconomic only]  vs  [Full model (+ barriers + clusters)]
```

| Element | Meaning |
|---------|---------|
| Bar height | Cross-validated ROC-AUC |
| Delta (uplift) | Full − Baseline |
| Positive uplift | Barriers add predictive signal beyond demographics |
| Near-zero / negative | Demographics already capture most signal (common with correlated features) |

**Actual LR uplifts:** +0.002 (ANC gap), +0.0017 (unmet FP) — small but positive.

**How to present honestly:** "The uplift is modest in AUC terms, which is expected when barrier probabilities are partially collinear with socioeconomic features. SHAP analysis still identifies barrier exposure as among the top individual-level predictors."

## 4. AOR vs SHAP comparison (dashboard Explainability page)

**Purpose:** Show that ML-based SHAP rankings ** broadly align** with the base paper's adjusted odds ratios while adding individual-level granularity.

| Rail | Source | Label in dashboard |
|------|--------|-------------------|
| A | Pradhan & De (2025) Table 2 | Base Paper Reference / Observed statistic |
| B | BarrierLens LR AOR + RF SHAP | Stage 1 ML Prediction / SHAP Explainability |

**How to read the comparison:**
- Features ranked highly in **both** rails → robust finding (e.g. education, wealth, media)
- Features high in SHAP but not in AOR → non-linear or interaction effects captured by trees
- Features high in AOR but lower in SHAP → may be collinear with other ML features

**Methodological caveat to state aloud:** Base paper N=108,785 ever-married women; BarrierLens N=724,115 full sample. Household/facility sub-items differ (v467f/i absent). Comparisons are **broadly comparable**, not identical.

## 5. Quick reference — which plot for which audience

| Audience question | Best plot |
|-------------------|-----------|
| "What matters most overall?" | SHAP bar chart |
| "Does high wealth reduce risk?" | SHAP beeswarm (color + position) |
| "Tell me about one high-risk woman" | SHAP waterfall |
| "How does barrier probability affect predictions?" | SHAP dependence plot |
| "Are barriers worth adding to the model?" | Barrier-uplift bar chart |
| "What groups exist in the data?" | Cluster profiles + cluster SHAP heatmap |
| "Is the model accurate?" | ROC curve + model_comparison_table.csv |
| "Does this match the published paper?" | AOR vs SHAP comparison |

## 7. One-paragraph explainability summary for reports

> BarrierLens explains model behaviour using a layered approach. Logistic regression odds ratios provide interpretable adjusted associations comparable to the base paper's AOR framework. Random Forest and XGBoost SHAP analyses quantify each feature's contribution to individual predictions, visualised through bar charts (global importance), beeswarm plots (direction and magnitude), waterfall plots (single-case decomposition), and dependence plots (feature-outcome relationships). For Stage 2, a barrier-uplift analysis compares models trained on socioeconomic features alone against models that additionally include out-of-fold barrier probabilities and K-Means cluster membership, testing whether barrier exposure adds predictive information beyond demographics. All explanations are framed as associational and predictive — not causal — consistent with observational survey data.
